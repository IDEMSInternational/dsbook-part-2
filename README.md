## Deployment

> **⚠️ IMPORTANT**: If you're seeing the repository README on GitHub Pages instead of the PreTeXt book, you need to configure GitHub Pages to use "GitHub Actions" as the source. See [QUICK_FIX.md](QUICK_FIX.md) for step-by-step instructions (takes 2 minutes).

This book is built using PreTeXt and is automatically deployed to GitHub Pages when changes are pushed to the main branch. See [DEPLOYMENT.md](DEPLOYMENT.md) for detailed information about the deployment process and available deployment methods.
